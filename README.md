# מחשבון המולד והלוח העברי

מחשבון מולד ולוח עברי כדף HTML יחיד ועצמאי, ללא צד־שרת, בשידור חי בכתובת:
https://shlomo-hecht.com/molad/

## קבצים

- `index.html` - המחשבון כולו (HTML+CSS+JS בקובץ אחד): מולד השנה וכל מולדותיה, דחיות ראש השנה, שנה מעוברת, אורכי חשוון וכסלו, יום השבוע של ראש השנה ופסח. כולל אפשרות חישוב לשיטת בן מאיר.
- `ben-meir.html` - דף הסבר: מאמר על מחלוקת רס"ג ובן מאיר על קביעת הלוח (פורסם במקור בערוץ 7, 28.11.24).

המקור המקורי של המחשבון: יישום שולחני ב־C++‎ (MFC) שאינו חלק ממאגר זה.
